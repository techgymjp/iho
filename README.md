# 摘発カウントダウン（Web版 MVP）

架空の繁華街「ネオン横丁」のバーを舞台にした、45秒で遊べるワンタップ偽装経営ゲーム。

> 本作はフィクションです。実在の人物・団体・店舗・事件とは関係ありません。
> 現実の無許可営業は法律で禁止されています。

## 遊び方
舞台は架空のバー「BAR 夜更し」の店内。表向きはただのバーだけど、実は女性キャストがカウンター席でお客さんの隣に座って接客している（無許可）。
22:00〜翌05:00（45秒）を摘発されずに稼ぎ切るゲームです。

- **🚪 案内する**：お客さんをカウンター席へ。キャストが自動で隣に座る。
- **お客さんをタップ**：お酒が出る（ビール→ハイボール→ワイン→シャンパン→シャンパンタワー）。飲み終わったらまたタップでおかわり。
- **🚪 ノック**：ドアの窓に映る影を確認。👮警察なら、隣に座っているキャストをタップしてカウンターの中へ逃がす。
- 警察がキャストに聞き込みをしたらアウト（摘発）。宅配や酔っ払いなどの空振りもある。
- 警察が帰ったら、カウンターの中のキャストをタップしてまた隣へ。
- 接待やお酒で「疑惑」が上がると警察が来やすくなり、MAXで踏み込まれる。03:00ごろの立入調査は必ず来る。
- スコア＝売上50＋来客20＋生存30（100点満点）

PC では Space/Enter＝案内、1〜3＝キャスト、Q/W/E＝お酒。

## 構成
```
index.html            画面（タイトル／ゲーム／立入調査・是正／結果）
css/style.css         ネオン調UI（9:16、セーフエリア対応、縦長端末は9:21まで拡張）
js/config.js          調整値を集約（時間・来客・売上・イベント・スコア・広告）
js/game.js            ゲーム本体（状態遷移・時間・来客・イベント・描画・保存・広告ダミー）
manifest.webmanifest  ホーム画面追加用
```
外部ライブラリなし。ビルド不要の静的ファイルです。

## ローカル実行
```bash
python3 -m http.server 8000
```
→ http://localhost:8000/

デバッグ用 URL パラメータ：`?seed=123`（イベント乱数を固定）、`?speed=4`（倍速）、`?noads=1`（広告枠を無効化）

## GitHub Pages
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定。

## 広告（AdMob）
Web版ではダミー表示（タイトルのバナー枠／結果後のインタースティシャル／任意のリワード「獲得ポイント2倍」）。
`js/game.js` の `Ads` オブジェクトが差し替えポイントです。ネイティブ化（Capacitor 等）時に AdMob SDK を接続し、
広告の読み込みに失敗してもゲームは継続します。

## 保存データ（localStorage）
ベストスコア、総プレイ回数、累計売上、累計ポイント、サウンド設定、チュートリアル完了、選択した営業形態。
